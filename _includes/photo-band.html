The two are NOT equal width: the pair is 2fr / 2.4fr and the tiles carry 2/3 and 4/5, which resolve to the same height because (2/3)/(4/5) is exactly 2/2.4. So the tops line up and the bottoms line up while the widths vary, and the run never reads as a column of identical slots. Alternate pairs flip which side is the wide one. A single is the same grid with one tile in it, so it takes a pair column's width and its phone behaviour without either being restated. Only the side needs saying.
