{%- comment -%} Renders editor text into HTML: **double asterisks** = bold, *single* = italic. Usage: {% include em.html t=site.data.home.hero.heading %} Optional k (+ i list index + f field name) wraps the output in a data-ed span for the inline editor: k="home:hero.heading", or k="pledge:items" i=forloop.index0 f="body". {%- endcomment -%} {%- comment -%} escape first: field values are plain text by contract (the CMS and inline editor never write HTML), so any markup in one is an accident or an injection — show it literally either way.
