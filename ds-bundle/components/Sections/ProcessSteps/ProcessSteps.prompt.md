# ProcessSteps

Numbered vertical timeline showing the booking-to-wedding process. Background is `var(--bg2)` (slightly darker warm cream).

## HTML

```html
<section class="proc">
  <div class="proc-wrap">
    <div class="proc-head">
      <span class="lab">How it works</span>
      <h2 class="disp">A process as considered as the flowers.</h2>
      <p>From first message to wedding day, you'll always know what's next.</p>
    </div>

    <div class="proc-step">
      <div class="proc-num">
        <span class="proc-when">Week 1</span>
        1
      </div>
      <div>
        <h3 class="disp">Initial consultation</h3>
        <p>We discuss your vision, venue, date, and budget.</p>
      </div>
    </div>

    <!-- Repeat .proc-step for each step -->
  </div>
</section>
```

## Rules

- Background: always `var(--bg2)` — this section creates a tonal break from surrounding `var(--bg)` sections.
- `.proc-num`: Cormorant Garamond, 2rem, `var(--accent)` color. Contains the step number plus a `.proc-when` timing chip above it.
- `.proc-when`: 0.74rem, uppercase, `var(--accent)` — appears above the number.
- Vertical rail: generated by `.proc-step::before` (a 1.5px `var(--line)` line connecting nodes). Automatic — don't add manually.
- Typically 3–5 steps. The last step's rail stops at the node (`height: 52px`).
- Step body: `var(--fg2)` color, max-width 62ch.
